# Kahoot Clone

Веб-платформа для проведения онлайн-викторин.

## Концепция

- Веб-платформа для проведения онлайн-викторин
- Игроки подключаются к комнате по PIN-коду с телефона
- Основной экран отображает вопросы, таймер, правильные ответы и рейтинг
- Телефон используется как контроллер для ответов

## Основные роли

### Хост
- Создание комнаты
- Выбор квиза
- Изменение настроек
- Начало и завершение игры

### Игрок
- Вход по PIN-коду
- Выбор имени и аватара
- Ответы на вопросы
- Просмотр результатов
